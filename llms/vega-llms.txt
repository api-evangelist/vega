# Vega

> Vega (vega.io) is "The Operating System for Agentic SecOps" — a post-SIEM security operations platform. Its Security Analytics Mesh (SAM) federates agentic detection, triage, and analytics across every security data source in place, with no ingestion or migration. Founded in 2024, backed by Cyberstarts, Accel, Redpoint, and CRV; raised $120M (announced September 2025).

## Platform

- [Platform](https://vega.io/platform): Security Analytics Mesh (SAM) — AI-native federated analytics over security data wherever it lives
- [AI-Powered Detections](https://vega.io/solutions/ai-powered-detections): detection engineering with continuous MITRE ATT&CK coverage assessment
- [Agentic Triage](https://vega.io/solutions/ai-soc-reduce-noise): autonomous investigation of every alert across all connected sources
- [Query at Source](https://vega.io/solutions/query-at-source): federated query across clouds and SaaS without moving data
- [Cost Savings](https://vega.io/solutions/cost-saving): eliminate legacy SIEM ingestion cost constraints
- [IR Readiness](https://vega.io/solutions/ir-readiness): assess coverage and close detection gaps
